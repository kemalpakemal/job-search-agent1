# Агент поиска работы — Сочи

Самостоятельное веб-приложение на Python для сбора вакансий, фильтрации по требованиям кандидата, оценки соответствия резюме, подготовки сопроводительных писем и сохранения истории.

## Что реализовано

- Полноценное управление из Telegram: меню, ручной запуск поиска, карточки вакансий, кнопки «Открыть», «Сохранить», «Пропустить», просмотр сопроводительного письма, статистика и статусы источников.
- Бот работает через официальный Telegram Bot API методом long polling; отдельная библиотека Telegram не нужна.
- Доступ к командам ограничивается Telegram ID владельца.

- Мобильный веб-интерфейс на русском языке.
- База SQLite; можно подключить PostgreSQL через `DATABASE_URL`.
- Поиск через публичный API HeadHunter (при наличии доступа; HH может потребовать регистрацию приложения/OAuth и корректный User-Agent).
- Поиск через официальный открытый API «Работа России» по коду региона 23 с дополнительной фильтрацией по городу Сочи.
- SuperJob: интеграция предусмотрена, нужен `SUPERJOB_APP_ID` от зарегистрированного приложения.
- Зарплата: фильтр 60 000 ₽ на руки; оценка NET из GROSS на основе годовой прогрессивной шкалы НДФЛ РФ; неопределённый тип зарплаты направляется на ручную проверку.
- Объяснимая оценка соответствия 0–100.
- Исключение дублей по источнику и ID.
- Сохранение вакансий и истории запусков.
- Генерация сопроводительного письма на основе подтверждённых сведений кандидата. Опционально можно подключить OpenAI-совместимую LLM через переменные окружения.
- Экспорт CSV.
- Периодический поиск каждые 12 часов при работающем сервере.
- Уведомления в Telegram о новых подходящих вакансиях после запуска команды /start.
- Не отправляет отклики автоматически. В интерфейсе можно открыть исходную вакансию и скопировать письмо.

## Источники

Автоматические API-коннекторы: HeadHunter, Работа России, SuperJob (после добавления ключа приложения).

Зарплата.ру, Работа.ру, Авито Работа и сайты работодателей показаны как ручные источники. В этой версии они не сканируются автоматически: не используется скрытый сбор данных или обход защит сайтов.

## Локальный запуск

Требуется Python 3.11 или новее.

1. Распакуй ZIP.
2. Открой терминал в папке проекта.
3. Создай виртуальное окружение и установи зависимости:

   `python -m venv .venv`

   Windows: `.venv\\Scripts\\activate`

   Linux/macOS: `source .venv/bin/activate`

   `pip install -r requirements.txt`

4. Скопируй `.env.example` в `.env` и задай `APP_PASSWORD`, а также контактный email в `HH_USER_AGENT`.
5. Запусти:

   `uvicorn main:app --host 0.0.0.0 --port 8000`

6. Открой `http://127.0.0.1:8000` и введи логин `user` и пароль из `APP_PASSWORD`, если пароль задан.

## Управление через Telegram

Полная пошаговая инструкция для настройки с телефона находится в `TELEGRAM_SETUP_RU.md`. Для загрузки кода с Android подготовлен `railway_github_upload.zip` (три файла для GitHub, полный проект вложен в `source.zip`). Кратко:

1. Создай бота через `@BotFather` командой `/newbot` и сохрани токен в секрете.
2. Разверни приложение на сервере с постоянным хранилищем.
3. Укажи в переменных сервера `TELEGRAM_BOT_TOKEN`.
4. Открой бота и отправь `/id`.
5. Добавь полученный номер в `TELEGRAM_ALLOWED_USER_IDS` и перезапусти сервис.
6. Отправь `/start`. Бот запомнит личный чат и сможет присылать уведомления.

Не отправляй токен бота в этот чат и не публикуй его в GitHub.

## Размещение в интернете

Рекомендуемый простой вариант — Railway с постоянным Volume:

1. Загрузи папку проекта в свой GitHub-репозиторий.
2. В Railway создай проект из этого репозитория.
3. Добавь Volume и подключи его к `/data`.
4. В Variables задай `DATABASE_URL=sqlite:////data/job_agent.db`, `APP_PASSWORD` (длинный случайный пароль), `HH_USER_AGENT`, при наличии — `SUPERJOB_APP_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
5. Railway использует Dockerfile/railway.json для сборки и запуска. Оставь один экземпляр приложения: планировщик и Telegram long polling встроены в один веб-процесс.
6. После деплоя проверь `/health`, затем открой корневую страницу.

Тариф Railway меняется; Hobby на текущей странице тарифов указан от $5/месяц, Free включает лишь $1 usage credit. У бесплатного хостинга могут быть ограничения сна/ресурсов. Для постоянных уведомлений и расписания нужен постоянно работающий процесс и постоянная БД.

## Переменные окружения

- `APP_PASSWORD` — пароль веб-интерфейса. Для публичного размещения обязательно задай.
- `DATABASE_URL` — SQLite или PostgreSQL.
- `TARGET_CITY` — город.
- `TRUDVSEM_REGION_CODE` — код региона API «Работа России»; для Краснодарского края в проекте установлен 23.
- `MIN_NET_SALARY` — минимум NET, по умолчанию 60000.
- `SEARCH_INTERVAL_HOURS` — периодический запуск, по умолчанию 12.
- `HH_USER_AGENT` — корректный User-Agent HeadHunter с контактным email разработчика.
- `SUPERJOB_APP_ID` — ключ приложения SuperJob.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — необязательные уведомления.
- `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — необязательная AI-генерация писем; совместимый endpoint должен поддерживать `/chat/completions`.

## Ограничения первой версии

- Поиск HeadHunter может быть ограничен правилами анонимного API и капчей; зарегистрируй приложение на dev.hh.ru, если публичный поиск не проходит.
- Подключение аккаунтов соискателя и отправка откликов пока не реализованы. Никакие реальные отклики не отправляются.
- На SuperJob нужен API App ID; авторизация соискателя и ID резюме понадобятся для разрешённой отправки отклика.
- API «Работа России» возвращает региональные открытые данные; приложение дополнительно проверяет город на «Сочи». Формат отдельных полей может меняться, поэтому результаты первого запуска следует сверить.
- Для оценки gross используется годовой пересчёт по прогрессивной шкале НДФЛ; личные вычеты, иные доходы и особенности налогового агента не учитываются. Поэтому оценка приблизительная.
- Скоринг объяснимый, на ключевых словах, а не полноценная нейросетевая экспертиза. Для LLM-генерации писем можно подключить совместимый API.
- Нужна проверка всех результатов вручную. Система не гарантирует актуальность объявления и точность зарплаты.

## Ограничения Telegram-версии

- Первое получение Telegram ID делается командой `/id`; до внесения ID в `TELEGRAM_ALLOWED_USER_IDS` остальные команды недоступны.
- Автоотклики не выполняются. Бот показывает исходную вакансию и готовое письмо, решение об отправке остаётся за пользователем.
- Для постоянного поиска сервер должен быть запущен постоянно. Если сервис засыпает или останавливается, расписание и бот тоже останавливаются.
- Не запускай несколько копий приложения с одним токеном: Telegram long polling должен работать в одном процессе.
