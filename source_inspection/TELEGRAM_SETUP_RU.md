# Настройка агента поиска работы через Telegram с телефона

После установки тебе не нужно открывать веб-панель: повседневная работа идёт в Telegram. Однако сам бот должен круглосуточно работать на сервере. Телефон используется только для управления ботом.

## 1. Создай Telegram-бота

1. Открой Telegram и найди `@BotFather` (официальный бот Telegram).
2. Отправь `/newbot`.
3. Укажи отображаемое имя, например `Поиск работы — Сочи`.
4. Придумай username, который заканчивается на `bot`, например `SochiWorkFinderBot` (если имя свободно).
5. BotFather выдаст токен. Скопируй его и сохрани в менеджере паролей или заметке с блокировкой.

**Не отправляй токен в переписку с ChatGPT, не публикуй его в GitHub и не вставляй в исходный код.** Токен — полный доступ к управлению ботом.

## 2. Размести программу на сервере — упрощённая загрузка с телефона

Для постоянной работы нужен хостинг. Чтобы не загружать десятки файлов по отдельности, подготовлен отдельный архив `railway_github_upload.zip`.

1. Скачай `railway_github_upload.zip` на телефон и распакуй его через приложение «Мои файлы» / «Files».
2. Создай приватный репозиторий GitHub с названием `job-search-agent`.
3. В распакованной папке будут три файла: `Dockerfile`, `railway.json` и `source.zip`. Загрузи именно эти три файла в корень приватного GitHub-репозитория. Внутри `source.zip` уже находится полный исходный проект; Dockerfile распакует его при сборке.
4. Открой Railway и создай проект через **Deploy from GitHub repo**, выбрав свой репозиторий.
5. В сервисе Railway создай Volume и смонтируй его в `/data`, чтобы база вакансий не терялась при новом деплое.
6. В Variables добавь значения, перечисленные ниже.
7. Запусти деплой и дождись успешного статуса сборки и запуска. В логах не должно быть ошибки Telegram API или импорта приложения.

После этой единственной настройки повседневное использование будет полностью из Telegram. Не делай репозиторий публичным: профиль и история вакансий относятся к персональным данным.

## 3. Переменные Railway

Добавь:

- `TELEGRAM_BOT_TOKEN` — токен, который выдал BotFather.
- `DATABASE_URL` — `sqlite:////data/job_agent.db`.
- `SEARCH_INTERVAL_HOURS` — `12`.
- `MIN_NET_SALARY` — `60000`.
- `TARGET_CITY` — `Сочи`.
- `TRUDVSEM_REGION_CODE` — `23`.
- `HH_USER_AGENT` — `JobSearchAgent/1.0 (твой-контактный-email)`.
- `APP_PASSWORD` — длинный уникальный пароль для дополнительной веб-панели.

`TELEGRAM_ALLOWED_USER_IDS` добавим на следующем шаге после получения твоего ID. Не нужно записывать токен в эту переменную.

При необходимости позже добавь `SUPERJOB_APP_ID` — ключ приложения SuperJob.

## 4. Закрепи бота за собой

1. После успешного запуска найди своего бота по username из BotFather.
2. Нажми **Start** или отправь `/id`.
3. Бот покажет твой числовой Telegram ID. Это не пароль и не секрет.
4. Вернись в Railway → сервис → Variables.
5. Создай переменную `TELEGRAM_ALLOWED_USER_IDS` и вставь туда только этот числовой ID.
6. Сохрани переменную и дождись автоматического перезапуска/сделай Redeploy.
7. Вернись в Telegram и отправь `/start`.

После `/start` бот сохранит ID личного чата в своей базе и сможет присылать уведомления. В групповые чаты бот по умолчанию не привязывается.

## 5. Как пользоваться ботом

Внизу Telegram появится постоянное меню:

- **Найти вакансии** — запустить сбор с подключённых API прямо сейчас.
- **Подходящие** — вакансии, прошедшие минимальные фильтры.
- **Проверить** — вакансии, где неясны зарплата, график или другие условия.
- **Сохранённые** — вакансии, которые ты отметил ⭐.
- **Статистика** — сколько вакансий собрано и сколько подходят.
- **Настройки** — текущие параметры поиска.
- **Источники** — состояние подключений и ошибок.

В карточке вакансии будут кнопки:

- **Открыть вакансию** — перейти к оригиналу на площадке.
- **Сопроводительное письмо** — получить персональный текст; его можно скопировать долгим нажатием.
- **Сохранить** — положить вакансию в сохранённые.
- **Пропустить** — убрать её из текущего списка.
- **Следующая** — показать следующую вакансию.

Команды на случай, если меню скрыто:

- `/search`
- `/jobs`
- `/review`
- `/saved`
- `/stats`
- `/sources`
- `/settings`
- `/id`

## 6. Что работает и что пока требует подключения

- HeadHunter — запросы идут через публичный поиск API; для стабильного доступа нужен корректный User-Agent и при необходимости регистрация приложения.
- Работа России — используется открытый API вакансий региона, с фильтрацией по Сочи.
- SuperJob — требуется `SUPERJOB_APP_ID`.
- Зарплата.ру, Работа.ру и Авито Работа — в этой версии ручные ссылки; бот не сканирует их скрытым способом.
- Telegram — меню, ручной поиск, карточки вакансий, письмо и уведомления.
- Автоматическая отправка откликов выключена. Отклик отправляется пользователем на сайте вакансии.

## 7. Важные условия

- Хостинг должен работать постоянно. Если сервис остановлен или засыпает, поиск и бот недоступны до его запуска.
- Для защиты данных используй приватный репозиторий GitHub.
- Не запускай два экземпляра приложения с одним Telegram-токеном.
- Не отправляй пароли, токены и коды подтверждения никому.
